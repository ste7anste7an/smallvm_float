*** Code Signing Process for MicroBlocks app ***

1. Unzip the app, run the codesign command, create archive, and submit for notarization:

  rm -rf Microblocks.app
  rm -f Microblocks.app.zip
  unzip out/microblocks-macos.zip
  ./signScript.sh
#  codesign --force --deep --options=runtime --entitlements entitlements.plist -s "Developer ID Application: John H Maloney" MicroBlocks.app
  ditto -c -k --keepParent MicroBlocks.app MicroBlocks.app.zip

xcrun notarytool submit \
  --apple-id "jmaloney@media.mit.edu" \
  --team-id YU23V8C72W \
  --keychain-profile "NotaryTool" \
  MicroBlocks.app.zip

2. Check notarization status:

xcrun notarytool history \
  --apple-id "jmaloney@media.mit.edu" \
  --team-id YU23V8C72W \
  --keychain-profile "NotaryTool" | head

3. Staple the notarization and re-zip:

xcrun stapler staple MicroBlocks.app
ditto -c -k --keepParent MicroBlocks.app MicroBlocks.app.zip

4. Upload to current release folder

Debugging:

1. To check locally if app would be accepted:

spctl --assess --verbose=4 --type execute MicroBlocks.app

2. To get error/status log (fill in the ID returned by the notarytool submit request):

xcrun notarytool log 5ffbe041-bc64-4673-b2bf-ac809a4744c7 \
  --apple-id "jmaloney@media.mit.edu" \
  --keychain-profile "NotaryTool" \
  --team-id "YU23V8C72W" \
  log.json
